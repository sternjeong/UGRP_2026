# 3분커리 (3-min Curri)

> "3분 만에 찾는 나만의 학술 경주로"
> 2026 POSTECH UGRP (기술창업트랙) — 오뚜기 부대

파편화된 대학 내 교육 자원(교과목, 연구실, 학사 제도)을 데이터화하여, 학생 개개인의 성향과 관심사에 최적화된 맞춤형 학술/진로 로드맵을 제공하는 AI 기반 진로 설계 및 추천 플랫폼입니다.

## 문제의식

포스텍은 무은재학부 제도(2학년 1학기까지 무전공), 자유로운 타과 수강 등으로 진로 설계의 **자유도는 최고 수준**이지만, 관련 정보는 강의계획서·에브리타임·학과 홈페이지에 흩어져 있어 가이드가 없습니다. 그 결과 학생들은 선배의 경로를 무비판적으로 답습하게 됩니다 — **"자유는 있는데 실행 가이드가 없다."**

| 대상 | 제공 가치 |
|---|---|
| 학생 | 탐색 비용 절감, 성향에 맞는 전공/연구 발견 |
| 학교 | 특정 분야 쏠림 없는 고른 자원 배분, 교육 만족도 향상 |

| 이름 | 직책 | 역할 |
|---|---|---|
| 최선우 | CEO | 소프트웨어 개발 총괄 |

## 핵심 기능 (MVP)

1. 관심사 기반 교과목/연구실 추천 (임베딩 매칭)
2. 맞춤형 선수과목 테크트리 생성 (학년별 분기)
3. 연구실 논문 키워드 트렌드 갱신 파이프라인
4. 타과 융합 연구실 추천 (통합 임베딩 공간에서 자연 확보)
5. 온톨로지 기반 전형적 경로 제시 — 권장이수체계도+온톨로지 그래프에서 도출한 "논리적으로 자연스러운" 경로 (실제 동료 수강기록 불사용)

## 기술 아키텍처

학생의 연구 방향성을 시간에 따라 진화하는 **상태(state)**로, 매 학기 수강 선택을 그 상태에 가하는 **제어입력**으로 보는 관점 위에서 다섯 개 축이 하나의 시스템으로 통합됩니다. 연구실적화 플래그십 축은 **A · D · E**입니다.

| 축 | 이름 | 역할 |
|---|---|---|
| **A** | 상태 표현 학습 (Deep Learning) | 도메인 특화 임베딩(BGE-m3 파인튜닝)으로 과목/연구실 유사도 매칭 — **현재 최우선** |
| B | 상태 추적 (Signal Processing) | 학생 수강 이력을 시계열 신호로 보고 관심 변화 추정 |
| C | 경로 계획 (Control/RL) | 테크트리 생성의 알고리즘 백엔드 — 스트레치 목표 |
| **D** | 온톨로지 (Formal Ontology) | OWL 2 DL + reasoner(HermiT/Pellet)로 논리적으로 검증된 지식그래프 |
| **E** | 생성/설명 계층 & LLM 벤치마크 | 온톨로지 검증 그래프 기반 GraphRAG로 추천 근거를 자연어 설명 |

축A·축D는 데이터 정제 파이프라인을 공유하고, 옵션3(`ResearchTopic` 노드에 앵커문장 부착) 방식으로 결합되어 Neo4j에 materialize된 뒤 축E와 MVP 서빙의 공통 기반이 됩니다. 전체 파이프라인과 축별 상세 플로우는 [`PROJECT_DESIGN.md` §12](PROJECT_DESIGN.md#12-전체-개발-워크플로우-신설-2026-08-03)에 다이어그램으로 정리되어 있습니다.

## 데이터 원칙

팀이 실제로 확보 가능한 데이터는 **인터넷에 이미 공개된 정형/텍스트 데이터뿐**입니다 (설문 등 별도 수집 불가, 비공개 학사 데이터 접근 불가). MVP 기능은 전부 이 제약 안에서 구현 가능하도록 설계했고, 부수적으로 "프라이버시-바이-디자인" 서사를 확보합니다.
